Практическая работа 1. Консольный калькулятор (Вариант 1)

1. Назначение проекта
Проект представляет собой консольное приложение на языке Python, предназначенное для выполнения базовых арифметических операций над двумя числами.

2. Какие задачи решает программа
- Считывает два числа и требуемую арифметическую операцию через консоль.
- Поддерживает следующие математические операции:
  - Сложение (`+`)
  - Вычитание (`-`)
  - Умножение (`*`)
  - Деление (`/`)
  - Целочисленное деление (`//`)
  - Остаток от деления (`%`)
  - Возведение в степень (`^`)
  - Выполняет валидацию пользовательского ввода:
  - Проверка корректности ввода числовых значений.
  - Обработка деления на ноль для операций `/`, `//`, `%`.
  - Обработка ввода неизвестной математической операции.

3. Инструкция по запуску
    1. Убедитесь, что на компьютере установлен Python версии 3.7 или выше.
    2. Сохраните код программы в файл `calculator.py`.
    3. Откройте терминал (консоль) в папке с файлом и выполните команду:
   ```bash
   python calculator.py

4. Пример

Введите первое число: 2
Введите операцию (+, -, *, /, //, %, ^): ^
Введите второе число: 8
Результат: 256
